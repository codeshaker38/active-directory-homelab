# Active Directory Home Lab

## Project Overview

This project documents a Windows Server Active Directory lab built to practice common Help Desk and junior Systems Administration tasks.

## Objectives

- Install Windows Server 2022
- Configure Active Directory Domain Services
- Create users and groups
- Configure Organizational Units
- Apply Group Policy
- Join Windows clients to the domain
- Perform common Help Desk administration
- Automate repetitive tasks with PowerShell

## Skills Demonstrated

- Active Directory
- Windows Server
- DNS
- DHCP
- Group Policy Management
- PowerShell
- Windows 11 Administration
- Troubleshooting
